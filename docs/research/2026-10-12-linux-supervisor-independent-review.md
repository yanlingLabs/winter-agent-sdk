# Linux tool supervisor service: independent review

2026-10-12. **Blocked at SDK leaf `30bb3f18`: four concrete boundary defects require correction before this service receives source acceptance.** Review concerns the leaf only, not its old ancestry. Root plans to cherry-pick reviewed changes onto the privacy-clean main. Overall confined startup remains false; no actual Linux service, namespace launcher, privileged code, VM, container, formatter or provider was executed by this reviewer. The correction agent received all findings and is implementing separate follow-up work.

**1. Ordinary saturation disables revocation/status.** `packages/runtime/src/guest/linux-supervisor.py:71` constructs one BoundedSemaphore(8). Every `_listener`, including root-only admin.sock (`:133`), must acquire it at `:120`. Eight admitted long-running tool calls retain every permit, so admin connections are immediately closed and root cannot revoke/status until an ordinary call finishes. A tool request may run for 600 seconds. The independent probe exercised the exact listener method with a mock socket and eight held ordinary permits: the admin connection closed without its handler running. Reserve a separate bounded admin capacity; test actual admin progress and cancellation with all ordinary slots occupied, using Linux peer credentials in the eventual CI fixture.

**2. Framing has an inactivity timeout, not a whole-frame deadline.** `frame_read` (`:48–58`) repeatedly receives header/body bytes. `_listener:123` sets socket timeout 3 seconds, which resets with every successful recv. A peer can retain one of the eight slots for an arbitrarily long trickled frame. The independent real socketpair probe sent a valid small frame slowly and observed acceptance after 3.57 seconds despite a 3-second socket timeout. Use one monotonic absolute deadline across the entire length prefix and body, and bound shutdown/disconnect handling. Test both slow partial headers and slow partial bodies; normal fragmentation must still work.

**3. Source protection can be bypassed between resolution and open.** At `:102–104`, the service resolves a source pathname, rejects protected-path overlaps, then independently opens its original spelling with O_NOFOLLOW. That flag guards only the final component. An independently executed temporary-directory probe passed the exact resolution/overlap check for allowed/nested, replaced ancestor allowed with a symlink to protected, then opened protected/nested using those exact flags; fstat confirmed the protected inode. No Linux/root service was needed for this filesystem-sequence reproducer. Pin/open under an enforced ancestor policy and bind protection/admitted identity to the actual descriptor, including protected roots/aliases. A string checked before a second resolution is not enough. Add an ancestor-swap regression, protected-store/control/environment alias negatives and an admitted-root positive control. Do not publish a claim of protected-source exclusion based on the current check/open pair.

**4. Initial control-message refusal leaks received descriptors.** `_run` receives SCM_RIGHTS at `:209` and validates the marker/flags/ancillary shape before taking ownership of its received FD. A wrong marker, extra data or another malformed envelope raises before `pidfd` is assigned; finally therefore never closes the installed descriptor. An independent actual SCM_RIGHTS transfer through the exact `_run` method with a non-executing mock launcher confirmed one received FD remains fstat-valid after refusal. Conversation debt is retained, which is correct, but does not close the FD. Own every visible received descriptor before envelope validation, close all on refusal, and retain only the validated pidfd. Truncated-control behavior must be fail-closed and tested on the target kernel; do not assume all installed descriptors are visible without evidence. The probe manually closes its received FD afterward and launches no child/service.
